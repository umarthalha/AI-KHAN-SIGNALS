Database Sync Manual

To persist your watchlists and brokerage holdings in your cloud database, execute these simple queries inside your **Supabase SQL Editor**:

-- 1. Custom Watchlists Table
create table watchlists (
  id uuid default gen_random_uuid() primary key,
  symbol text unique,
  created_at timestamp default now()
);

-- 2. Real Holdings Table
create table brokerage_holdings (
  id text primary key,
  symbol text,
  buy_date text,
  buy_price numeric,
  qty int,
  created_at timestamp default now()
);

Once tables are instantiated and credentials updated, your selections sync instantly on page load!
